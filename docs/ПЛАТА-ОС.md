# ПЛАТА-ОС v7.0 — операционка на 2.8" экране

Прошивка: **`release/firmware/board-os-FULL.bin`** → адрес `0x00000`

## Подключение экрана (2.8" TFT 240x320 SPI v1.2 + тач XPT2046)

Сенсор HW-937AB — это и есть XPT2046, работает по тому же SPI.

| Экран | Плата | Пин |
|---|---|---|
| VCC | 3V3 | 3.3 В |
| GND | GND | земля |
| CS | D6 | 14 → **15** |
| RESET | D7 | 13 → **4** |
| DC/RS | D9 | 2 → **2** |
| MOSI | D11 | 23 |
| SCK | D12 | 18 |
| LED | 3V3 | подсветка |
| MISO | D13 | 19 |
| T_CLK | D12 | 18 |
| T_CS | D3 | 26 → **33** |
| T_DIN | D11 | 23 |
| T_DO | D13 | 19 |
| T_IRQ | D2 | 25 → **36** |

> В таблице справа — реальный GPIO. Колонка «Плата» — подпись на гребёнке.

Если тач не попадает по кнопкам — **калибровка**: зажми кнопку D4 на плате,
подай питание, отпусти. Появятся 4 кружка — нажми по очереди.

## Что внутри

**Рабочий стол** — 6 плиток: Подсветка · Часы · Компьютер · Настройки · Инфо · Игры

**Часы** — время по NTP (Хабаровск, +10), дата, день недели и погода из интернета

**Компьютер** — блокировка, сон, выключение, перезагрузка, громкость, mute,
**⚡ Разбудить** (Wake-on-LAN шлёт сама плата)

**Настройки** — выбор Wi-Fi прямо с сенсора (экранная клавиатура с кириллицей),
яркость экрана, IP компьютера, MAC для разбудки, калибровка

**Инфо** — чип, память, флеш, температура, сеть, адрес

**Подсветка** — 6 цветов, яркость, 6 эффектов, выключение

## Порядок первого запуска

1. Прошить `board-os-FULL.bin` на `0x00000`
2. Включить — экран спросит Wi-Fi
3. Настройки → Найти сети → выбрать свою → ввести пароль экранной клавиатурой
4. Готово. Адрес платы покажется на экране

## Сколько занято

- Флеш: 1 131 600 Б из 1 310 720 (**86%**)
- Шрифты с кириллицей: 10.5 КБ на 3 размера

## Прошивка собирается так

```fish
cd ~/esp32-flasher/examples/board-os
arduino-cli compile -b esp32:esp32:esp32 --output-dir /tmp/fw .
```

Шрифт перегенерировать: `python3 tools/gen_font.py`
Настройки дисплея — в `User_Setup.h` рядом со скетчем.
