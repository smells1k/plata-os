# Прошивки — что куда

## Главное правило для этой платы

**Всё прошивать полным образом на адрес `0x00000`.**

Обычный `.bin` на `0x10000` у этой платы не всегда запускается (загрузчик
один раз вычистили «Стереть flash»). Поэтому берём файлы `*-FULL.bin`.

| Файл | Адрес | Что делает |
|---|---|---|
| `web-play-FULL.bin` | `0x00000` | игры + полный пульт светодиода (Wi-Fi) |
| `web-panel-FULL.bin` | `0x00000` | панель: виртуальный экран, данные платы, светодиод |
| `board-check-FULL.bin` | `0x00000` | самодиагностика: чип, flash, heap, I2C, WiFi |
| `tft-probe-FULL.bin` | `0x00000` | проверка контакта экрана (мигает: зелёный/жёлтый/красный) |
| `tft-display-FULL.bin` | `0x00000` | тест экрана: полосы + TFT OK + счётчик |
| `peripherals-test-FULL.bin` | `0x00000` | тест всех модулей (нужны припаянные гребёнки) |
| `ws2812-gpio5-red3-blue4-FULL.bin` | `0x00000` | твой тест: 3 красных + 4 синих |

Обычные `.bin` (без `-FULL`) — те же программы без загрузчика, на `0x10000`.
Держим на случай, если понадобится быстрая перезапись при целом загрузчике.

## Wi-Fi прошивки (web-play, web-panel)
- Сеть: **ESP32-Flasher**
- Пароль: **12345678**
- Адрес: **http://192.168.4.1** (обязательно `http`, не `https`)
- Интернета в этой сети нет — это норма, сеть локальная

## Признак, что прошивка запустилась
`web-play` при старте гасит светодиод и зажигает его красным вполсилы.
Если диод остался прежнего цвета — прошивка не стартовала.

## Настройки в приложении
- Адрес: `0x00000 — полный образ`
- Скорость: `460800`
- «Проверка после записи» — включена
- «Полное стирание flash» — **выключена** (FULL-образ сам всё перезапишет)
