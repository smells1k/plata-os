# ПЛАТА-ОС

Своя «операционка» для ESP32: экран, сенсор, пульт управления компьютером.
Управление ПК — **только по кабелю USB**. Wi-Fi нужен для часов, погоды и обновлений.

Последний релиз: **v10.2**

---

## Обновиться

Плата сама проверяет GitHub и ставит новую прошивку.

**Дополнительно → Обновление → Установить с GitHub**

Если на столе внизу появилась строка `↑ есть v10.3` — значит обновление уже лежит
и ждёт нажатия. Проверка идёт сама раз в 6 часов.

Ещё способы:

| способ | как |
|---|---|
| браузер | `http://<адрес платы>` → выбрать `plata-os-app.bin` |
| кабель | `plata-os-full.bin`, адрес `0x00000`, скорость 460800 |

## Что в репозитории

| папка | что там |
|---|---|
| `firmware/` | готовые прошивки |
| `sketch/` | исходники прошивки (Arduino, ESP32) |
| `app/` | окно на компьютере, Python |
| `.github/workflows/` | сборка прошивки при выходе тега |

---

## Как выходит новая версия

```fish
git tag v10.3
git push origin v10.3
```

GitHub Actions собирает `.bin` и прикрепляет к релизу.
Платы по всему миру видят его сами.

Смотреть сборку: вкладка **Actions**.

## Окно на компьютере

```fish
python3 app/ЭКРАН-ПЛАТЫ.py
```

| клавиша | действие |
|---|---|
| колесо | прокрутка |
| Ctrl + колесо | масштаб |
| `R` | перерисовать |
| `T` | попросить плату перерисовать |
| `F` | вписать в окно |
| `U` | прошить по Wi-Fi |

Команды платы на ПК: блокировка, сон, выключение, перезагрузка, громкость,
mute, play/pause, next/prev, Wake-on-LAN.

## Сборка вручную

```fish
arduino-cli core install esp32:esp32
arduino-cli lib install TFT_eSPI XPT2046_Touchscreen
mkdir -p tmp/board-os && cp sketch/*.ino sketch/*.h tmp/board-os/
arduino-cli compile -b esp32:esp32:esp32 --output-dir out tmp/board-os
```

Плата: ESP32-DOWD-V3, 4 МБ flash, схема разделов `default` (два слота приложения).
