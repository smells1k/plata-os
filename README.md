# ПЛАТА-ОС

Своя «операционка» для ESP32 — с экраном, сенсором и пультом управления компьютером.
Управление ПК идёт **только по кабелю USB**. Wi-Fi нужен для часов, погоды и обновления по воздуху.

Текущая сборка: **10.0**

---

## Что внутри

| папка | что там |
|---|---|
| `firmware/` | готовые прошивки — качать отсюда |
| `sketch/` | исходники прошивки (Arduino, ESP32) |
| `app/` | окно на компьютере на Python — «ЭКРАН-ПЛАТЫ» |
| `docs/` | как подключить и что умеет |

---

## Прошивка

### Первый раз — кабелем

1. Скачай `firmware/ПЛАТА-ОС.bin`
2. Залей по адресу `0x00000`, скорость `460800`
3. На рабочем столе платы справа вверху должно быть **10.0**

### Дальше — по воздуху, без провода

1. Плата подключена к Wi-Fi (Настройки → Найти сети)
2. В браузере открой `http://<адрес платы>` — адрес виден в Настройках
3. Выбери `firmware/ПЛАТА-ОС-для-WiFi.bin`, нажми **Прошить**
4. Плата сама перезапустится, на экране будет процент

Полный 4-мегабайтный файл тоже подойдёт: плата отбросит заголовок и прошьёт только программу.

## Окно на компьютере

```fish
python3 app/ЭКРАН-ПЛАТЫ.py
```

Что умеет:

| клавиша | действие |
|---|---|
| колесо мыши | прокрутка |
| Ctrl + колесо | масштаб |
| `R` | перерисовать экран платы |
| `T` | попросить плату перерисовать |
| `F` | вписать в окно |
| `U` | прошить плату по воздуху |

Команды платы выполняются на ПК: блокировка, сон, выключение, перезагрузка,
громкость, mute, play/pause, next/prev, Wake-on-LAN.

## Как это собрано

Прошивка: Arduino IDE / arduino-cli, плата **ESP32 Dev Module**
(ESP32-DOWD-V3, 4 МБ flash), библиотеки `TFT_eSPI` и `XPT2046_Touchscreen`.

```fish
arduino-cli core install esp32:esp32
arduino-cli lib install TFT_eSPI XPT2046_Touchscreen
arduino-cli compile -b esp32:esp32:esp32 sketch/
```

Файлы прошивки:

- `board-os.ino` — рабочий стол, экраны, связь с ПК, обновление по Wi-Fi
- `os_extra.ino` — настройки, игры, фонарик, диод
- `os_games.ino` — игры
- `ui_core.h` — цвета, шрифты, отрисовка, протокол экрана
- `ui_font.h` — сгенерированный шрифт с кириллицей
