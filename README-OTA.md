# Обновление прошивки

Три пути. Первый раз — только кабелем, дальше как угодно.

## 1. Плата сама (лучший)

Плата в Wi-Fi → **Дополнительно → Обновление → Установить с GitHub**.

Она стучится на `api.github.com/repos/smells1k/plata-os/releases/latest`,
сравнивает версии, качает `.bin` из релиза, пишет во второй раздел
и перезапускается. Если оборвалось — остаётся на старой прошивке.

## 2. Браузер

`http://<адрес платы>` → выбрать `ПЛАТА-ОС-для-WiFi.bin` → Прошить.

## 3. Кабель

`ПЛАТА-ОС.bin`, адрес `0x00000`, скорость `460800`.

---

## Как выходит новая версия

```fish
git tag v10.2
git push origin v10.2
```

GitHub Actions собирает прошивку и прикрепляет файлы к релизу.
Плата увидит новый релиз сама.

Проверить сборку: вкладка **Actions** в репозитории.
